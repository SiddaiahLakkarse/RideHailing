# RideFlow React frontend`n`nReact + TypeScript + Vite frontend for the RideHailing platform.`n`n## Run locally`n`n```powershell`nnpm install`nnpm run dev`n``` `n`nThe default mode is local mock data. Copy `.env.example` to `.env` and set `VITE_USE_MOCKS=false` with `VITE_API_URL` to connect to the ASP.NET Core API.`n`n## Workspaces`n`n- `/admin` - operations overview, rides, drivers, riders, and payments`n- `/rider` - booking, estimate, active trip, and history`n- `/driver` - availability, offers, active trip, and earnings`n`nThe workspace switcher in the sidebar makes each role available in development. Authentication tokens are stored in local storage and requests use the bearer token when API mode is enabled.`n
